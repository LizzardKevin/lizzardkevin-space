# Profile 单场景连续运镜合同

2026-09-10，本轮覆盖此前双模型分散重组方案。Profile 的六个标题沿同一份 Rhino 场景连续运镜；Cultural 在空白区域补充六组摄影体积粒子。

## 唯一源模型与构建

源模型：`profile+6+scenes.3dm`，米制，SHA256 `d63398c24da5e1bca908f0969d8cbc4ceb020885230a25a0eee47ac8b0c865a9`。原3dm只读。包含四个命名镜头 Student/Career/Photo/Band、527个可见根对象、1,086,740个缓存网格三角形；`pillarette` 图层为72个柱体，`people`为117个双部件实例。

构建步骤（私有源和检查包目录由调用者提供，不写入public）：

```powershell
python scripts/extract-profile-rhino-study.py --source PRIVATE_MODEL.3dm --output-dir PRIVATE_STUDY
python scripts/bake-profile-rhino-cache.py --source PRIVATE_MODEL.3dm --study-dir PRIVATE_STUDY --output-dir apps/web/public/particles/profile --verify-determinism
```

提取器展开块实例，尊重对象/图层可见性，完整保留保存的render mesh和相机矩阵。提取与烘焙均核对源哈希。新构建不需要历史两份模型、旧检查包或旧的motion-contract。

manifest v2只包含一个`model`，主缓存`scene.bin`使用PVR1格式：16字节头+float32位置+snorm16法线+uint16运动组索引，每点20字节，共270,000点/5,400,016字节。135,000点分给72个柱体（每柱1,875点），另外135,000点按场馆表面积加权采样。舞台桁架6倍、阵列音响10倍、人群8倍权重；当前分别15,070、6,640、27,144点。所有源坐标统一映射为(x,z,-y)*0.1。

旧两组主缓存已移除。旧计划文档仅保留历史设计记录，不再作为实现或构建依据。

## 六章相机

Student、Career、Photo、Band精确沿用新Rhino文件的保存位置、朝向、投影和lens shift。用户明确授权由网页设计后两个镜头：Cultural在模型左侧空白区域展示六组摄影粒子场景，Experimental是整个场景的远景总览，集中定义在`extendProfileShots`，便于未来替换为新Rhino视角。

真实渲染相机固定，粒子通过统一的view变换模拟运镜。四个Rhino章节保持同一模型，不解构源模型；Cultural的额外摄影粒子独立循环重组。阅读中心前后各0.12屏短暂停留，运动段使用五次缓动；反向滚动严格回溯。Career→Photo沿场馆外侧绕行并从实际窗洞进入；Band→Cultural经窗洞离开场馆，Cultural→Experimental沿场馆外侧拉远回望。路径位置采用centripetal Catmull–Rom弧长取样，四元数插值朝向，段末与原镜头一致。

六章长度维持1.2个视口，左右交替文字，标题无底色/阴影，不吸附慢滚。快速滚动仅在200ms内至少10次同方向wheel事件触发；静默180ms后用0.78秒对齐标题，输入可中断。

## 自主运动与指针

72柱各自随机初相位和基础频率，加连续相位调制变化速度；高度为源高度12%–130%，绕源柱底伸缩。117人群实例共用头/身体的刚体XY轻移（映射为世界X/负Z），不拆散身体、不累积漂移。运动由独立时间控制，停止滚动仍运行。

鼠标视差水平±15°、垂直±7.5°，平滑3/s；局部反馈平滑8/s，沿用WorkDetail的Gaussian增亮、微放大和按粒子间距标定的微位移。整组点云有NDC横向.002/纵向.005的轻微呼吸，地面保持固定。

Student/Career的真实作品名来自对应现有双语内容，最多同时3个不同作品/柱体，单次3–8秒，随机上升柱触发，ASCII与真实名称闪现。文字在柱顶最高投影边缘上方18px，13px字号，不可点击。

## 地面与窗外

单场景保留新源文件地面，另外生成48,000点世界XZ地面，固定在柱底下方.002。76%点围绕72个柱体底部高斯分布，余下使用延伸至70单位的对数远景尾部；按距最近柱体的距离降低密度、亮度、点径和透明度，远处在边界前已不可见，形成无限地面的观感。沿用WorkDetail的1.3px点径与.32基础亮度；地面不浮动，不依赖相机朝向。

DUMBO是之前批准的补充几何，保留45,000点，并从新检查包的Photo窗口重新推导portal，不依赖旧3dm。街道低一个楼层，桥塔、桥面和悬索共用斜向桥轴，建筑AABB提供随当前视角变化的遮挡。室内只显示穿过窗洞的外景，镜头移到窗外后解除窗洞裁切，建筑遮挡始终有效。额外点不占主场景预算。

## OpenShaders 首尾名片与统一柔光（2026-09-15）

首屏名字及末屏联系方式使用用户提供的 @lizzardkevin OpenShaders 名片。原始 WGSL 保存在 `references/lizzardkevin-openshaders.wgsl`，TSL移植保留81层折叠、形变、呼吸和OKLCH颜色循环；按显像管网点重新呈现，颜色保留34%，高光稍偏冷白。约4.4px错列点阵，按亮度改变点径，边缘渐隐，窄屏重新取景。每帧按点计算场，最大80,000点；不创建第二个GPU设备或rAF循环。

Hero→Student、Experimental→Links沿现有滚动进度交叉渐变，首尾模型隐藏，中间维持现有六章镜头。交叉渐变只改变辐射亮度，不同时压缩点径和透明度，以免中途显著变暗。所有背景共用一个高光Bloom：strength .18、radius .32、threshold .52，模拟轻微1/4黑柔；HTML标题、正文、联系方式不进入后期。透明画布保持预乘alpha，避免光晕被错误放大成白雾。离开Profile暂停，卸载时释放shader网格、后期pass及bloom目标。

## 网点飞行与局部紫色交互（2026-09-15）

共用ScrollPageShell内的HazardRule及其样式、动画已移除，适用于所有滚动内容页。名片网点在指针附近约0.20 NDC纵向尺度内呈现紫/粉紫色，使用原有平滑指针位置、Gaussian衰减与有限范围，点径仍按原始中性亮度计算，避免变色时缩小。

本轮替换纯渐变：每个网点稳定绑定一个实际源粒子ID，开头选当前Student镜头可见柱体，结尾选Experimental镜头可见的源模型。屏幕行序匹配限制无序交叉；网点沿有错峰的弧线从屏幕阵列飞往模型，在最后28%交接给完整点云。柱体和人群运动通过`profileParticleMotionNode`共用计算，停滚时进度不推进，反向滚动沿同一路径还原。原模型与源缓存不变。

首尾目的地的位置、运动与随机属性使用同一个交错GPU缓冲，避免超过WebGPU的8个顶点缓冲限制。对应关系在模型加载或视口尺寸改变时重建，不逐帧执行CPU匹配。首尾保留此前统一轻柔高光处理。

## 接管黑点修复（2026-09-15）

此前飞行网点沿用SpriteNodeMaterial的透明队列，但退出时只把RGB压暗，opacity保持不变；它在不透明模型之后绘制，从而以黑点覆盖已接管的柱群。现改为保持网点颜色、通过opacity退出，并显式声明transparent=true。源模型保持正常亮度，通过点径平方根控制覆盖面积进入，不再用RGB衰减生成黑色不透明像素。回归测试检查实际材质节点图：退出权重必须进入网点opacity，不能进入颜色；模型权重只进入size。
