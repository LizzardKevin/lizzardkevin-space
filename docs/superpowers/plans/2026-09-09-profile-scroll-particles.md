# Profile full-screen particle narrative implementation plan

> For agentic workers: use subagent-driven-development for the isolated cache task; integrate and review the shared renderer/UI in this task.

**Goal:** Replace the desktop Profile's long lists with full-viewport alternating text islands and reversible scroll-driven Rhino particle scenes.

**Architecture:** One Profile host persists inside ArchiveHub. A pure timeline reads actual section offsets in `.ark-scroll`. GPU point transforms simulate the two authored camera views inside each model; cross-model transitions reach a fully dispersed point field before gathering the same stable particle IDs into the next model. Reuse the existing renderer factory, WebGPU/WebGL2 fallback and instanced Sprite/TSL particle architecture. Work and mobile behavior remain separate.

**Tech stack:** React, TypeScript, Three/TSL r184, existing Lenis scroll bus, offline rhino3dm/numpy.

The user has authorized implementation using the September 2 contract and September 7 plan, with these newer requirements taking precedence: each title occupies a full viewport; no full work lists; Student→Career is particle motion simulating camera movement; Career→Photo fully disperses and regathers. Follow-up answers confirm continuous scrolling, six chapters, all 117 people instances and autonomous column/crowd micro-motion. Camera/scatter use a reversible scroll clock; micro-motion uses a separate clock paused while Profile is inactive. Source `.3dm` files remain read-only. Culture/Experiments use an ambient field until authored assets exist.
